Getting Started

Initial Setup

Before using AI analysis, add your Anthropic API key in Settings (Cmd+,). You can get a key at console.anthropic.com.

Workflow

  1. Click Add Files or drag-drop PDFs/folders to load cards
  2. Cards are automatically processed with OCR to extract family names
  3. Review extracted names in the card list — use sidebar filters to focus on cards that need attention
  4. Click the AI button (per card) or AI Analyze (all cards) for better accuracy
  5. Edit names manually or select from the Candidates dropdown
  6. Click Rename to rename files with extracted names
Note: You can load cards from multiple folders! They accumulate rather than replacing previous loads. Identical files at different locations are automatically detected and merged.
