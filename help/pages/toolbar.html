Toolbar

Buttons

  • Add Files — Add PDF files or folders from anywhere (Cmd+O). You can add from multiple sources; cards accumulate rather than replace.
  • AI Analyze — Analyze all loaded cards with Claude AI to extract family names. Requires an API key (set in Settings).
  • Rename — Rename files based on extracted names. Shows a confirmation dialog before renaming.
  • Clear — Remove all loaded cards and start over.

Controls

  • Year — Year to include in renamed file names (e.g., "2025"). Required before renaming.
  • Search — Filter cards by file name or family name (Cmd+F).
