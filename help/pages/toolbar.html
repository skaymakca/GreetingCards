Toolbar

Buttons

  • Add Files — Add PDF files or folders from anywhere (Cmd+O). You can add from multiple sources; cards accumulate rather than replace.
  • AI Analyze — Analyze cards with Claude AI to extract family names (Cmd+Shift+I). When 2 or more cards are selected, analyzes only the selected cards; otherwise analyzes all visible (filtered) cards. The menu label and tooltip update to show the count and scope. Requires an API key (set in Settings).
  • Rename — Rename files based on extracted names (Cmd+R). Shows a confirmation dialog before renaming. Also available via File → Rename Files.
  • Clear — Remove all loaded cards and start over. Also available via File → Clear All.
  • Clear AI Results — Clear AI analysis results for visible or selected cards (File → Clear AI Results). Preserves OCR data and manual entries. Use this to re-analyze cards after changing the AI model in Settings.

Controls

  • Year — Year to include in renamed file names (e.g., "2025"). Required before renaming.
  • Search — Filter cards by file name or family name (Cmd+F).
