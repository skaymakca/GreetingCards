Toolbar

Buttons

  • Add Files/Folders — Add PDF files or folders from anywhere (can add multiple sources)
  • AI Analyze — Analyze all loaded cards with Claude AI (requires API key)
  • Rename — Rename files based on extracted names (handles multiple directories)
  • Clear — Remove all loaded cards and start over

Controls

  • Year — Year to include in renamed file names
  • Search — Filter cards by file name or family name
