# Keyboard Shortcuts

## General

- <kbd>Cmd+O</kbd> — Open files or folders
- <kbd>Cmd+Shift+R</kbd> — Reload (re-check loaded files for changes)
- <kbd>Cmd+Shift+I</kbd> — AI Analyze (visible or selected cards)
- <kbd>Cmd+R</kbd> — Rename Files
- <kbd>Cmd+,</kbd> — Open Settings
- <kbd>Cmd+F</kbd> — Focus search/filter field
- <kbd>Cmd+W</kbd> — Close Help / What's New / Licenses windows
- <kbd>Esc</kbd> — Defocus text entries or clear search

## Navigation

- <kbd>Up</kbd> / <kbd>Down</kbd> — Navigate cards in list
- <kbd>Shift+Up</kbd> / <kbd>Shift+Down</kbd> — Extend card selection
- <kbd>Left</kbd> / <kbd>Right</kbd> — Navigate pages in preview

## Selection

- <kbd>Cmd+A</kbd> — Select all cards
- <kbd>Cmd+Shift+A</kbd> — Select none
- <kbd>Cmd+Delete</kbd> — Remove selected cards

## Editing

- <kbd>Cmd+X</kbd> — Cut
- <kbd>Cmd+C</kbd> — Copy
- <kbd>Cmd+V</kbd> — Paste

## Zoom Controls

- **Shift + Click** — Zoom in (cursor shows +)
- **Option + Click** — Zoom out (cursor shows -)
- **Scroll Wheel** — Zoom in/out at cursor
- **Fit button** — Reset to fit window
